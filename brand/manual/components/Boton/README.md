# Boton

Botón de acción en tres variantes: primario, secundario y enlace.

- **Primario:** fondo `accion`, texto `on-accion`, `radio-medio`, relleno `espacio-3` × `espacio-4`, texto en `etiqueta`. Va uno solo por vista, para la acción principal ("Ver requisitos", "Enviar corrección").
- **Secundario:** fondo transparente, borde de 1.5px en `borde-fuerte` y texto en `tinta`. Para acciones alternativas ("Reportar un error").
- **Enlace:** texto en `celeste-tinta` subrayado. Se usa para ir a la fuente oficial, que siempre abre en una pestaña nueva y lleva el ícono `external-link`.
- El texto dice exactamente lo que pasa, con un verbo en voseo: "Descargá el checklist", no "Descarga" ni "Click acá".
- Altura mínima de 44px para tocar cómodo en celular. Foco: anillo de 2px en `foco`.
- **Lo que pone quien lo usa:** el texto, la variante y, si hace falta, un ícono Lucide a la izquierda.
